# TankBot 3D-printed parts

**Get these from Printables:** [TankBot on Printables](https://www.printables.com/model/1869360-tankbot).
That page is the maintained source, with print settings, photos and updates, and it is the page to
link to.

This folder is a backup copy of the model files, in case Printables is ever unavailable. `.stl` files
are ready to slice and print; `.f3d` files are the Fusion 360 sources for modifying the designs.
